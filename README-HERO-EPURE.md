# Mise à jour — hero épuré, look affiche centré

## Ce qui change
- **Contenu réduit** au strict nécessaire : titre + description courte +
  1 seul bouton ("Découvrir notre école").
- Retirés : l'accroche ("Apprendre aujourd'hui..."), le second bouton
  WhatsApp, la ligne "Discipline. Suivi. Innovation.", le badge circulaire
  "Bonjour. / Hello.". Rien n'est perdu fonctionnellement : le bouton
  WhatsApp flottant (en bas à droite sur toutes les pages) et la devise
  (déjà présente dans le footer) prennent le relais.
- **Disposition centrée** : tout le texte est maintenant centré sur
  l'image, façon affiche, au lieu d'être aligné à gauche.

## Où copier quoi
- `src/app/globals.css` → remplace le fichier existant
- `src/app/page.tsx` → remplace le fichier existant

`npm run dev` et regarde le rendu du hero.
