# Mise à jour — texte courant en Lexend

## Ce qui change
`--sans` passe de Lato à **Lexend** — une police conçue à partir d'études
sur la lisibilité pour améliorer la fluidité de lecture. Bon argument pour
le site d'une école, et elle couvre nativement toutes les graisses utilisées
sur le site (400, 500, 600, 700), donc plus d'approximation de poids comme
avec Lato.

## Où copier quoi
- `src/app/globals.css` → remplace le fichier existant
- `src/app/layout.tsx` → remplace le fichier existant (nouveau lien Google Fonts)

`npm run dev` et vérifie le rendu du texte courant.
